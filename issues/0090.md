## Summary
Request for a mid/side EQ, described as a switchable Revamp. Use case: cleaning up stereo problems, for example removing side content in the low end.

1. Button "m" edits the mid signal only, the spectrum behind the curve shows the mid part.
2. Button "s" edits the side signal only, the spectrum shows the side part.
3. Both on shows both curves and spectra together (mixed view), if that makes sense.
4. Optional: prelisten buttons that solo mid or side.

The concept image shows three Revamp panels: "mids only mode" with an M button and a low shelf curve, "sides only mode" with an S button and a high-pass at about 690 Hz, and "mixed/sum mode" with both curves and both spectra drawn over each other.

## Current state
1. Revamp is stereo linked: the same seven filters run on left and right (`crates/stock-devices/device-revamp/src/lib.rs:229` to `:246`), with one output spectrum (`crates/stock-devices/device-revamp/src/lib.rs:248`). No mid/side mode.
2. The audio composite infrastructure already has split containers: `AudioEffectCompositeBox` (broadcast), `StereoCompositeBox` (L/R) and `FrequencySplitBox` (bands). The schema comment names mid/side as a planned further split (`packages/studio/forge-boxes/src/schema/devices/audio-effects/StereoCompositeBox.ts:11`).
3. Engine: the distributor enum has `Broadcast`, `Stereo`, `Frequency` (`crates/engine/src/lib.rs:136` to `:141`, comment at `:134` lists mid/side as a future variant). The processor side is `DistributorMode` (`crates/engine-env/src/composite_mix.rs:43`), with per-mode branch buffers (`crates/engine-env/src/composite_mix.rs:76` to `:113`). TS registrations live in `packages/studio/core-wasm/src/engine-modules.ts:145` to `:161`.
4. The Mastering device does mid/side EQ internally for Matchering only (`crates/device-mastering/src/lib.rs:12`), not user editable.

## Analysis
Two designs:

1. **Mid/Side split composite (fits the existing seam).** A `MidSideSplitBox` with two fixed entries. The distributor encodes `M = (L+R)/2`, `S = (L-R)/2` and hands entry 0 the signal `(M, M)` and entry 1 the signal `(S, -S)`. The composite already sums the entry outputs, and `(M', M') + (S', -S')` decodes straight back to `L' = M'+S'`, `R' = M'-S'`, so no decoder node is needed. Works with any stereo linked effect in each branch (Revamp, compressor, saturation), not just EQ. A Revamp in each entry gives the requested M and S editing, the spectrum of each Revamp shows its branch. Entry mute/solo gives the prelisten.
2. **Mid/side mode inside Revamp.** New fields (mode, a second band set for side) and a second spectrum. Closer to the mockup with both curves in one panel, but doubles Revamp's schema and editor and only helps the EQ.

Option 1 reuses everything that exists and is bit-identical for existing projects because it is a new box. Exactness: `(L+R)/2 + (L-R)/2` is not bit exact in float, an empty split is a near (not exact) bypass, unlike the stereo split.

## Possible solution
1. Schema: `MidSideSplitBox` in `packages/studio/forge-boxes/src/schema/devices/audio-effects/`, same fields as `StereoCompositeBox`, factory creates two fixed entries labelled Mid and Side.
2. Engine: add `Distributor::MidSide = 3` (`crates/engine/src/lib.rs:136`, keep the `// WASM CONTRACT` in sync with `engine-modules.ts`) and `DistributorMode::MidSide` with two branch buffers encoded as above in `composite_mix.rs`.
3. Register the box in `EFFECT_COMPOSITES` (`packages/studio/core-wasm/src/engine-modules.ts`), add adapter, editor (reuse the stereo split editor with M/S labels) and the effect factory entry.
4. Optional later: a "Mid/Side" preset that drops a Revamp into each entry, and an overlay of both Revamp curves if the mixed view is wanted.
5. Tests: Rust test that an empty mid/side split reproduces the input within float tolerance and that a gain on the side entry changes only `L-R`.

## Complexity
medium. One new box (forge-boxes, boxes, adapters), one distributor variant in `crates/engine` and `crates/engine-env`, the registration in `core-wasm`, a small editor in `packages/app/studio`. Option 2 (mode inside Revamp) would be larger.
