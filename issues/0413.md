## Summary
The reporter wants faster audio region editing. The screenshot (viewed) shows the audio editor with a viola region and a red marked silent gap he wants to cut out, with the right part moving left to close the gap and snapping. Doing this in the timeline is slow and needs deep zoom. Requested:
1. Region context menu: reverse, normalize, convert to mono.
2. Audio editor: trimming, phase inversion, a clip volume envelope that also changes the drawn waveform.
3. Warp markers should draw a vertical line down through the waveform.

## Current state
1. Convert to Mono is in the region menu (`packages/app/studio/src/ui/timeline/tracks/audio-unit/regions/RegionContextMenu.ts:168`, commit `0bca570d8`).
2. "Edit in Sample Editor" opens the destructive sample editor (`RegionContextMenu.ts:176`), which has reverse, normalize, amplify, fades, mono and more (`packages/lib/dsp/src/sample-effects/`). There is no phase invert effect, amplify only scales by a positive gain (`packages/lib/dsp/src/sample-effects/amplify.ts:7`).
3. Regions have a static `gain` (field 17) and fades. The `AudioRegionBox` has an `events` pointer to a value event collection (field 5), read by the adapter (`packages/studio/adapters/src/timeline/region/AudioRegionBoxAdapter.ts:131`), but the engine does not use it as gain (`crates/engine/src/audio_unit/tracks/audio.rs:85` lists no key 5).
4. No ripple delete or "delete range and close gap" exists in the timeline or the audio editor.
5. Warp markers are drawn only in their own lane (`packages/app/studio/src/ui/timeline/editors/audio/WarpMarkerEditor.tsx`).

## Analysis
Reverse, normalize and mono are available, two of them only through the sample editor, which creates a new sample. The main missing piece is the gap removal: split at two positions, delete the middle, move the rest left by the gap length. This can be built from existing region split and move operations. A clip gain envelope would need the engine to read the region event collection and the waveform painter to scale peaks by it.

## Possible solution
1. Add "Phase Invert" as a sample effect in `packages/lib/dsp/src/sample-effects/` (gain of minus one).
2. Add direct region menu entries for Reverse and Normalize that run the sample effect and repoint the region, like Convert to Mono does.
3. Add a "Delete Range" or ripple delete: with a time range selected in the audio editor or timeline, split all affected regions at both ends, delete the inside, and shift later regions on that track left by the range length, snapped to the grid.
4. Clip gain envelope: engine reads the region `events` collection as gain in `crates/engine/src/audio_unit/tracks/audio.rs`, the audio editor gets a gain lane, the waveform painter applies it.
5. Draw a faint vertical line from each warp marker through the waveform in `AudioEditorCanvas`.

## Complexity
medium for items 1, 2, 3 and 5 (sample effects, region menu, a ripple operation in core with tests, canvas painting). Item 4 alone is medium to large (engine, adapters, editor, painter).

## Open questions
1. Should Reverse and Normalize be non destructive region flags (engine side) or destructive new samples like Convert to Mono?
2. Ripple delete: only the edited track, or all tracks?
