## Summary
Request from Instagram, filed by André. When a region in the middle of a row is deleted, the following regions should move left automatically to close the gap (ripple cut or ripple delete), instead of leaving an empty space.

## Current state
1. Deleting regions just deletes the boxes: `packages/app/studio/src/ui/timeline/tracks/audio-unit/regions/RegionsArea.tsx:107` (shortcut) and the "Delete" entry in `RegionContextMenu.ts:76`.
2. No ripple code exists anywhere (`grep -i ripple` finds nothing in app, core or adapters).
3. Building blocks: region positions live on the region boxes (`box.position`), `RegionEditing.cut` splits regions (`packages/studio/adapters/src/timeline/RegionEditing.ts:6`, used at `RegionsArea.tsx:203`), `RegionOverlapResolver` and `RegionClipResolver` handle overlaps (`packages/studio/core/src/ui/timeline/RegionOverlapResolver.ts:30`). Timeline level data that would need shifting in a global ripple: markers, tempo track, signature, loop area (`packages/studio/forge-boxes/src/schema/std/timeline/TimelineBox.ts:22` to `:64`).

## Analysis
Two common variants:
1. Ripple per track: deleting regions moves every later region on the same track left by the deleted span. Simple and safe, touches only region positions on that track.
2. Ripple all tracks or ripple a time range: removes a time span (selection range or loop area) from the whole song, splitting regions at both edges and moving everything after it, including automation regions, markers, tempo and signature events, key and chord tracks. More useful for arrangement editing, much more to get right.
Design questions: what span to remove when several regions with gaps are selected on a track (sum of each region's duration, or the merged covered span), and what to do with regions that start inside the span but are not selected (overlaps).

## Possible solution
1. Add a "Ripple Delete" command (region context menu plus a shortcut such as Shift+Delete) in `RegionsArea.tsx` and `RegionContextMenu.ts`.
2. Per track: sort selected regions by position, compute the covered spans (merging overlaps), delete them, and move every unselected region with `position >= spanEnd` left by the accumulated span length. Run inside one `editing.modify`.
3. Put the logic in a pure helper next to `RegionEditing` (adapters) with tests: single region, several regions with gaps, overlapping regions, regions after the last span, multiple tracks.
4. Later, optionally, "Delete Time" for the loop area across all tracks: split at both edges with `RegionEditing.cut`, delete the inside, shift regions, markers, tempo and signature events, and harmony track events.

## Complexity
medium for per track ripple delete (one helper with tests plus UI wiring in `packages/app/studio/src/ui/timeline/tracks/audio-unit/regions/`). A global time range ripple across all timeline data would be large.
