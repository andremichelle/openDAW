## Summary
Kilian built VibePlugin, a plugin format that loads a WASM file plus an HTML UI at runtime, working in native DAWs and on the web. He asks whether openDAW could load `.vstai` plugins, or whether a plugin browser is planned, and offers to export to WebCLAP instead.

Thread:

1. André prefers WebCLAP and asks what VibePlugin adds that WebCLAP cannot do.
2. Kilian asks for a browser collecting open source WebCLAP plugins. André points to webclap.opendaw.studio (Import), which runs the openDAW SDK, so a plugin that works there works in the studio.
3. Kilian offers an AI plugin that writes WebCLAP plugins from text, using the user's own Anthropic key stored locally. André: worth a try.
4. Kilian may start a repo collecting WebCLAP plugins. André points to the in-studio upload of own WebCLAP plugins (manual `community-webclaps`).

## Current state
1. No VibePlugin or `.vstai` support exists in the code.
2. WebCLAP hosting exists (`crates/stock-devices/device-wclap`, `device-wclap-instrument`, `device-wclap-midi`), with community upload documented in `packages/app/manual/public/community-webclaps.md`.
3. A device browser dialog is planned (`plans/device-browser-dialog.md`), no `browser-refresh` branch exists locally.

## Analysis
1. Nothing is needed in openDAW if Kilian exports to WebCLAP. Supporting a second plugin format would duplicate the WebCLAP host layer (parameters, state, UI embedding, collaboration) for a format with no stated extra capability.
2. The remaining open points are outside the codebase: a WebCLAP collection repo and an AI plugin generator by Kilian.

## Possible solution
1. Kilian exports VibePlugins as WebCLAP and tests them on webclap.opendaw.studio.
2. Close the issue as answered, or keep it open only to track the AI WebCLAP generator if André wants to follow it.

## Complexity
unknown. Nothing to implement for the WebCLAP route. Native `.vstai` support would be large (a new plugin host layer) and is not planned.

1. Close as answered, since WebCLAP is the route both sides agreed on?
