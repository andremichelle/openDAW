## Summary
The reporter proposes adding the dough-samples collection (the default sample set of Strudel, github.com/felixroos/dough-samples) to openDAW's default samples. It is a light, cohesive set aimed at electronic music, with some extras like crows and tubular bells.

## Current state
1. The default samples come from a folder tree at `assets.opendaw.studio/samples/index.json` (`packages/app/studio/src/opendaw-api/OpenSampleAPI.ts:27-29`). The studio renders whatever folders the index contains (`packages/app/studio/src/opendaw-api/SampleIndex.ts:4-6`). Adding samples needs no studio code change, only new files and index entries on the asset server (upload path via the admin and api sibling repos).
2. The commits listed as referencing #255 (2fc22895c and siblings, 2026-03-27, "disable EditContext") predate this issue and belong to an older issue numbered 255. They are unrelated.
3. Nothing of dough-samples has been added.

## Analysis
This is a content and licensing decision, not a code task. dough-samples bundles sets of different origin (drum machine collections, orchestral and piano sets and others). Each subset carries its own license, and some popular live coding sample packs have unclear provenance. openDAW samples are served as standard samples to every user and may end up in published music, so each subset needs a license that permits redistribution and use.

## Possible solution
1. List the subsets in dough-samples and the license of each.
2. Pick only subsets with clear permissive licenses (CC0, CC BY with attribution).
3. Convert to the openDAW sample format, add BPM and names, upload to `assets.opendaw.studio/samples`, and add a "Dough" folder (or merge by category) to `index.json`.
4. Add attribution where a license requires it (manual or an about page).

## Complexity
small. No studio code, only asset upload and `index.json` edits on the server side, plus license review and attribution.

## Open questions
1. Does André want an external collection in the default library at all, or rather keep the library curated?
2. Which subsets have licenses that allow redistribution as openDAW samples?
