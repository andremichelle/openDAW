## Summary
Monitoring sources were registered with the worklet's `MonitoringRouter` only. The restart after an engine error (`Project.startAudioWorklet`) builds a new worklet with an empty router, nothing registered the sources again.

## Fix
`EngineFacade` keeps the registered sources and registers them with every new worklet in `setWorklet`. Test: `EngineFacade.test.ts` (monitoring sources).

## Progress
1. Fixed on next-release, uncommitted.
2. Chrome: With Effects monitoring, Debug > Restart Audio Engine, the return is back at once (L = R ×0.50 for the forced mono input).
