## Summary
A collection issue for the CUBED device (303 style bass synth with an internal step sequencer). Requested pattern operations:
1. Export pattern to a MIDI clip or file.
2. Import pattern from a MIDI clip or file.
3. Octave adjust (-1 / +1).
4. Double pattern (append a copy of the pattern to itself).
5. Reverse pattern (left to right).
6. Invert pattern (up to down).

## Current state
1. Pattern storage: 16 patterns per device, each with `length` (1..64) and 64 packed int32 steps (note 7 bits, gate, slide, accent) in `packages/studio/forge-boxes/src/schema/devices/instruments/CubedDeviceBox.ts:44`. Pack and unpack in `packages/studio/adapters/src/devices/instruments/Cubed/CubedStep.ts:14`.
2. Existing pattern operations on the adapter: `readCurrentPattern`, `writeCurrentPattern`, `clearCurrentPattern`, `randomizeCurrentPattern`, `rotateCurrentPattern` (`packages/studio/adapters/src/devices/instruments/CubedDeviceBoxAdapter.ts:46` to `:81`).
3. UI: Random, rotate `<` `>` and Clear buttons in `packages/app/studio/src/ui/devices/instruments/CubedDeviceEditor/PatternControls.tsx:67`. Copy, Paste, Copy as JSON, Paste from JSON and Load ABL .pat in `CubedDeviceEditor/CubedPatternActions.ts:46`, reachable from the device menu (`CubedDeviceEditor.tsx:53`) and the Pattern field context menu (`PatternControls.tsx:57`).
4. None of the six requested operations exist. JSON copy and ABL import are a partial substitute for import and export, but not MIDI.
5. Engine semantics (needed for MIDI conversion): steps are sixteenth notes, a gated step lasts `GATE_FRACTION` 0.55 of a step, a slide holds 1.05 steps so it overlaps the next note, accent maps to velocity at or above 100/127 (`crates/stock-devices/device-cubed/src/pattern.rs:8` to `:38`).

## Analysis
1. Octave, double, reverse and invert are pure step transforms, the same shape as `rotateCurrentPattern`. Points to decide:
   1. Octave: clamp to 0..127 or refuse when a note would leave the range.
   2. Double: length becomes `min(2 * length, 64)`, steps copy into `length..2*length`.
   3. Reverse: reverse the first `length` steps. Slides belong to the step before the next note, so a literal reverse moves each slide to the wrong transition. A slide flag on step i should move to the step that precedes the old step i in the reversed order (shift slide flags by one).
   4. Invert: mirror notes around a pivot (lowest plus highest gated note, or the pattern's first note), only gated steps matter.
2. Export to MIDI: build a note list from the steps (position `i * SEMI_QUAVER`, duration 0.55 step or the merged tie length for slides, velocity from accent) and either create a `NoteRegionBox` on the device's track or pass it to `NoteMidiExport` (`packages/studio/core/src/project/NoteMidiExport.ts:9`). A shared TS helper mirroring `pattern.rs` keeps it consistent with playback, including groove if wanted (probably not).
3. Import from MIDI or a note region: quantize note starts to sixteenths, one note per step (monophonic, highest or last wins), gate on, accent from velocity >= 100, slide when a note overlaps the next step's note on. Length = ceil(region length in sixteenths), capped at 64. MIDI file parsing exists for timeline import (`packages/app/studio/src/ui/timeline/MidiImport.ts`).

## Possible solution
1. Add `transposeCurrentPattern(semitones)`, `doubleCurrentPattern()`, `reverseCurrentPattern()`, `invertCurrentPattern()` to `CubedDeviceBoxAdapter`, implemented as pure functions on `CubedPatternData` with unit tests next to `AblPattern.test.ts`.
2. Add buttons or menu entries in `PatternControls.tsx` and `CubedPatternActions.ts` ("Octave Up", "Octave Down", "Double", "Reverse", "Invert").
3. Add `CubedPatternData.toNotes` and `fromNotes` with tests for slide, accent and length round trips.
4. Menu entries "Export Pattern to Note Region" (on the device's track at the playhead), "Export Pattern to MIDI File", "Import Pattern from MIDI File". Optionally a region context menu entry "Send to CUBED pattern".

## Complexity
medium. Transforms are small and local (adapter plus PatternControls). MIDI and region conversion adds a converter with tests in `packages/studio/adapters/src/devices/instruments/Cubed/` and menu wiring in `packages/app/studio/src/ui/devices/instruments/CubedDeviceEditor/`. No schema or engine change.
