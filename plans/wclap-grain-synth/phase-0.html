Grain synth, phase 0 previews

Each frame is the device panel surface, 512 × 176. Drop an audio file on any waveform (or LOAD) to see it in all four. Click on the waveform to move the grain position, drag the parameters vertically (Shift for fine), switch the sections. The grains are simulated, an LFO sweeps POS and CUT so the modulation display moves. Mix the waveform style, the control style and the colour below each frame.
